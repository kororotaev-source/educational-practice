# Финальная сводка проекта

## Назначение
Консольное приложение на Python для учёта компьютерного оборудования в кабинетах колледжа. Хранит инвентарные записи в JSON, позволяет просматривать, добавлять, искать, изменять и удалять их, сохраняет данные между запусками.

## Исходные требования
- Консольный интерфейс, Python 3.11+.
- Хранение в `data/inventory.json`, без СУБД.
- CRUD: просмотр, добавление, поиск, изменение, удаление.
- Валидация обязательных полей и состояний.
- Сохранение данных между запусками.
- Автоматические тесты pytest.
- Документация Markdown.
- Docker — дополнительно, при наличии.

## Реализованные функции
- Просмотр списка оборудования в табличном виде.
- Добавление записи: тип, наименование, кабинет, состояние.
- Проверка уникальности инвентарного номера.
- Валидация пустых полей и допустимых состояний.
- Поиск по инвентарному номеру и кабинету.
- Изменение кабинета и состояния записи.
- Удаление с подтверждением.
- Сохранение и загрузка JSON между запусками.
- Обработка отсутствующего, пустого и повреждённого файла.
- Автоматические тесты pytest.
- Инструкция пользователя и список ограничений.

## Структура проекта
- `main.py` — меню и пользовательские сценарии.
- `inventory.py` — операции с записями и валидация.
- `storage.py` — чтение и запись JSON.
- `data/inventory.json` — файл данных.
- `tests/` — автоматические тесты.
- `README.md` — назначение, установка, запуск.
- `USER_STORIES.md` — требования и критерии приёмки.
- `USER_GUIDE.md` — инструкция пользователя и ограничения.
- `sprint-01.md` … `sprint-06.md` — журналы спринтов.
- `requirements.txt` — зависимости.
- `Dockerfile` — при наличии Docker.

## Ограничения
- Интерфейс только консольный.
- Хранение — JSON, без СУБД.
- Автоматическое восстановление повреждённого JSON не выполняется.
- Изменяются только кабинет и состояние.
- Поиск только по номеру и кабинету.
- Многопользовательская работа не поддерживается.
