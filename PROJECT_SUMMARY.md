# Финальная сводка проекта

## Назначение
Консольная система учёта оборудования компьютерных классов колледжа. Приложение написано на Python, использует JSON для локального хранения и предоставляет операции просмотра, добавления, поиска, изменения и удаления.

## Реализованные возможности
- просмотр записей;
- добавление с автоматическим назначением уникального номера;
- поиск по номеру, типу, наименованию, кабинету и состоянию;
- изменение типа, наименования, кабинета и состояния;
- удаление с подтверждением;
- автоматические временные метки `created_at` и `updated_at`;
- сохранение и загрузка JSON;
- обработка отсутствующего, пустого и повреждённого файла;
- совместимость со старыми записями без `updated_at`.

## Архитектура
- `main.py` — консольное меню и пользовательский ввод;
- `inventory.py` — бизнес-логика, CRUD, поиск и валидация;
- `storage.py` — JSON, проверка структуры и безопасное сохранение;
- `tests/` — автоматические тесты;
- `data/inventory.json` — 10 демонстрационных записей.

Подробности: `ARCHITECTURE.md`.

## Проверка качества
Последний запуск `python -m pytest -q tests`: **37 passed**. Подробный отчёт: `TEST_REPORT.md`. Ручная проверка интерфейса и установки на целевом компьютере вынесена в отдельный чек-лист и должна быть отмечена после фактического выполнения.

## Ограничения
- только консольный интерфейс;
- локальное JSON-хранилище без СУБД;
- одновременная многопользовательская работа не поддерживается;
- повреждённый JSON требует ручного исправления или восстановления;
- Docker не включён в обязательную поставку.
