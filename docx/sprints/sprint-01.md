# Спринт 1 — тест-кейсы и журнал дня

## 1. Тест-кейсы Спринта 1
### T-01. Запуск приложения и отображение главного меню
**Приоритет:** Высочайший.

**Предусловия:** Python 3.11+ установлен; есть прототип или готовый вариант главного меню; проект склонирован из репозитория.

**Шаги:**
1. Открыть терминал в корне проекта.
2. Выполнить `python main.py`.
3. Дождаться вывода меню.

**Ожидаемый результат:**
- Программа запускается без ошибок и трейсбеков.
- Выводится текстовое меню: «Показать оборудование», «Добавить», «Найти», «Изменить», «Удалить», «Выход».
- Отображается приглашение ко вводу.

**Фактический результат:** *Все работает согласно ожидаемому результату*.

**Статус:** *Пройден*.

**Комментарий:** Разработчик молодец.

### T-02. Просмотр демонстрационных записей
**Приоритет:** высокий.

**Предусловия:** приложение запущено ; в `data/inventory.json` лежит ≥5 демо-записей.

**Шаги:**
1. В главном меню выбрать «Показать оборудование».
2. Просмотреть вывод.
3. Вернуться в меню.

**Ожидаемый результат:**
- Выводится список.
- Для каждой записи видны: инвентарный номер, тип, наименование, кабинет, состояние.
- Кириллица отображается корректно.
- После вывода программа возвращается в меню, не завершаясь.

**Фактический результат:** *Все работает согласно ожидаемому результату*

**Статус:** *Пройден*

**Комментарий:** Разработчик молодец.

**Приоритет:** средний.
