## T-07. Поиск оборудования по номеру и кабинету
**Приоритет:** высокий.

**Предусловия:** приложение запущено; в списке есть запись с номером `1` в кабинете `101`, а также записи в других кабинетах.

**Шаги:**
1. Выбрать «Поиск оборудования».
2. Ввести существующий номер `1`.
3. Повторить поиск, введя несуществующий номер `9999`.
4. Повторить поиск, введя кабинет `101`.
5. Повторить поиск, введя кабинет `999`.

**Ожидаемый результат:**
- По существующему номеру показывается карточка записи.
- По несуществующему номеру и кабинету выводится «Не найдено».
- По кабинету `101` показываются все записи этого кабинета.
- После каждого поиска программа возвращается в меню и не падает.

**Фактический результат:** *Заполняется QA.*

**Статус:** *Ожидает проверки.*

**Комментарий:** Объединяет позитивный и негативный поиск по номеру и кабинету. Не дублирует T-02 (просмотр списка) и T-05 (дубль при добавлении).

- Программа не падает и возвращается в меню.

**Статус:** *Ожидает проверки.*
