# Тестирование проекта

Подробные результаты автоматического тестирования приведены в `../../TEST_REPORT.md`.

## Автоматические тесты

Команда запуска из корня проекта:

```bash
python -m pytest -q tests
```

Последний фактический прогон после изменений: **37 passed, 0 failed**.

Тесты проверяют CRUD-операции, валидацию, уникальность инвентарных номеров, поиск, сохранение, загрузку, обработку пустого/повреждённого файла и совместимость со старой структурой данных.

## Замечание

Статус «Автотест» означает, что проверка выполняется тестовым кодом. Проверки интерфейса и установки на учебном компьютере необходимо подтвердить непосредственно перед защитой; в отчёте не указываются как выполненные без такой проверки.
