# Система учёта инвентаря компьютерных классов

## Назначение проекта
Консольное приложение на Python для учёта компьютерного оборудования 
(ПК, мониторы, принтеры и др.) в кабинетах колледжа. 

Программа решает проблему потери информации об оборудовании: 
она хранит все инвентарные записи в едином файле, позволяет их 
просматривать, добавлять, искать, изменять и удалять, а также 
сохраняет данные между запусками.

## Пользовательские сценарии

### Первый запуск
1. Запустите `python main.py`.
2. Если файла `data/inventory.json` ещё нет, программа создаст его автоматически с пустым списком.
3. Выберите «Показать оборудование» — появится сообщение «Список пуст».
4. Добавьте первую запись через пункт «Добавить оборудование».

### Сохранение данных
1. Добавьте, измените или удалите запись.
2. Выйдите из программы.
3. Запустите программу снова — изменения должны сохраниться.
4. Данные хранятся в `data/inventory.json` в формате `{"version": 1, "items": [...]}`.

### Повреждённый файл данных
1. Если файл `data/inventory.json` повреждён, программа сообщит об ошибке и не будет перезаписывать его молча.
2. Исправьте файл вручную или восстановите из резервной копии.
3. После исправления запустите программу снова.

### Пустой файл данных
1. Если файл существует, но пуст, программа считает список пустым.
2. Добавление записей работает как обычно, файл перезаписывается в корректном формате.

### Ограничения Спринта 4
- Хранение выполняется в JSON, без СУБД.
- При повреждённом JSON автоматическое восстановление не выполняется — требуется ручное исправление или резервная копия.
- Docker является дополнительным инструментом и не блокирует запуск через Python.
