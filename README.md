# Система учёта инвентаря компьютерных классов

## Назначение проекта
Консольное приложение на Python для учёта компьютерного оборудования 
(ПК, мониторы, принтеры и др.) в кабинетах колледжа. 

Программа решает проблему потери информации об оборудовании: 
она хранит все инвентарные записи в едином файле, позволяет их 
просматривать, добавлять, искать, изменять и удалять, а также 
сохраняет данные между запусками.
