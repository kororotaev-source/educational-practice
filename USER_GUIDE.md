# Инструкция пользователя

## Назначение

Приложение предназначено для учёта оборудования компьютерных кабинетов. Оно позволяет просматривать, добавлять, искать, изменять и удалять записи. Изменения сохраняются в `data/inventory.json`.

## Требования и запуск

Нужен Python 3.11 или новее. Откройте терминал в каталоге проекта.

**Windows:**
```powershell
py -3 -m venv .venv
.venv\\Scripts\\activate
python -m pip install -r requirements.txt
python main.py
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Главное меню

- `1` — показать оборудование;
- `2` — добавить оборудование;
- `3` — поиск оборудования;
- `4` — изменение оборудования;
- `5` — удаление оборудования;
- `0` — выход.

Во время ввода `0` отменяет текущую операцию, если программа ожидает поле или выбор записи.

## Работа с приложением

### Просмотр

Выберите `1`. Программа покажет номер, тип, наименование, кабинет, состояние и дату добавления. Если записей нет, будет выведено «Список пуст».

### Добавление

Выберите `2` и заполните поля:
- тип оборудования;
- наименование (не менее двух символов);
- кабинет (не менее одного символа);
- состояние: `исправно`, `требует ремонта` или `списано`. Можно ввести `1`, `2` или `3`.

Инвентарный номер назначается автоматически. Новая запись получает одинаковые начальные значения `created_at` и `updated_at`.

### Поиск

Выберите `3`, затем укажите поле поиска:
1. инвентарный номер;
2. тип;
3. наименование;
4. кабинет;
5. состояние.

Введите искомое значение. Поиск нечувствителен к регистру и находит совпадения по части значения. Если совпадений нет, выводится сообщение об отсутствии результата.

### Изменение

Выберите `4`, введите номер записи, затем выберите поле:
- тип;
- наименование;
- кабинет;
- состояние.

Номер записи изменить нельзя. Пустые значения и недопустимые состояния отклоняются. При успешном изменении обновляется `updated_at`.

### Удаление

Выберите `5`, введите номер. Программа покажет запись и запросит подтверждение. Введите `y`, чтобы удалить; любой другой ответ отменяет операцию.

### Сохранение

Изменения сохраняются после каждой операции. После закрытия и повторного запуска записи загружаются автоматически.

## Формат данных и обработка ошибок

Файл данных расположен по адресу `data/inventory.json`. В нём хранится объект с номером версии формата и массивом `items`.

- Если файла нет, он создаётся автоматически.
- Если файл пуст, программа трактует его как пустой список.
- Если JSON повреждён или содержит записи неверной структуры, программа сообщает об ошибке и не перезаписывает исходный файл.
- Старые записи, в которых отсутствует `updated_at`, при загрузке получают `updated_at`, равный `created_at`.

## Известные ограничения

- Приложение имеет только консольный интерфейс.
- Данные хранятся в одном локальном JSON-файле.
- Одновременная работа нескольких пользователей с одним файлом не поддерживается.
- Повреждённый JSON не восстанавливается автоматически.
- Инвентарный номер назначается автоматически и не редактируется.
- Docker не требуется для запуска.

## Частые проблемы

- **Программа не запускается:** проверьте `python --version` и убедитесь, что активировано виртуальное окружение.
- **Не удаётся установить pytest:** выполните `python -m pip install -r requirements.txt`.
- **Запись не находится:** проверьте значение и выбранное поле поиска.
- **Ошибка загрузки JSON:** сделайте копию файла и проверьте его синтаксис и структуру; не заменяйте повреждённый файл пустым, если нужно сохранить данные.
