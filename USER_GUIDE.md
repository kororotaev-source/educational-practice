# Инструкция пользователя

## Назначение программы
Консольное приложение для учёта компьютерного оборудования в кабинетах колледжа. Позволяет просматривать, добавлять, искать, изменять и удалять инвентарные записи. Данные сохраняются в `data/inventory.json` между запусками.

## Требования
- Python 3.11 или новее.
- Терминал (командная строка).
- Файлы проекта: `main.py`, `inventory.py`, `storage.py`, папка `data/`.

## Установка и запуск
1. Открыть терминал в корне проекта.
2. При необходимости создать виртуальное окружение:
   - Windows: `python -m venv venv` и `venv\Scripts\activate`
   - Linux/macOS: `python3 -m venv venv` и `source venv/bin/activate`
3. Установить зависимости: `pip install -r requirements.txt`
4. Запустить программу: `python main.py`

## Главное меню
После запуска отображается меню:
- `1` — Показать оборудование
- `2` — Добавить оборудование
- `3` — Поиск оборудования
- `4` — Изменение оборудования
- `5` — Убрать оборудование
- `0` — Выход

Для выбора ввести число и нажать Enter.

## Сценарии работы

### Просмотр оборудования
1. Выбрать `1`.
2. Программа выведет таблицу: номер, тип, наименование, кабинет, состояние, дата добавления.
3. Если записей нет, появится сообщение «Список пуст».

### Добавление оборудования
1. Выбрать `2`.
2. Ввести тип, наименование, кабинет, состояние.
3. Состояние можно ввести словом или числом: `1` — исправно, `2` — требует ремонта, `3` — списано.
4. При успешном добавлении появится сообщение об успехе.
5. При пустом поле, недопустимом состоянии или повторяющемся номере запись не создаётся, выводится понятная ошибка.

### Поиск оборудования
1. Выбрать `3`.
2. Ввести инвентарный номер или кабинет.
3. По существующему значению показываются найденные записи.
4. По несуществующему значению выводится «Не найдено».
5. Пустой ввод не приводит к аварийному завершению.

### Изменение оборудования
1. Выбрать `4`.
2. Ввести инвентарный номер записи.
3. Если запись найдена, изменить кабинет и/или состояние.
4. Недопустимое состояние отклоняется с понятной ошибкой.
5. Изменения сохраняются и видны в списке.

### Удаление оборудования
1. Выбрать `5`.
2. Ввести инвентарный номер записи.
3. Подтвердить удаление: `y` — удалить, `n` — отменить.
4. При отказе запись остаётся; при согласии — удаляется из списка.
5. По несуществующему номеру выводится «Не найдено».

### Сохранение данных
1. Все изменения сохраняются в `data/inventory.json`.
2. После перезапуска данные загружаются автоматически.
3. Если файла нет при первом запуске, он создаётся с пустым списком.
4. Если файл повреждён, программа сообщает об ошибке и не перезаписывает его молча.

## Известные ограничения
- Интерфейс только консольный, графического интерфейса нет.
- Хранение — JSON-файл, без СУБД.
- При повреждённом JSON автоматическое восстановление не выполняется: требуется ручное исправление или резервная копия.
- Изменять можно только кабинет и состояние; тип, наименование и инвентарный номер при изменении не редактируются.
- Поиск выполняется по инвентарному номеру и кабинету; поиск по наименованию и типу не реализован.
- Docker является дополнительным инструментом и не блокирует запуск через Python.
- Многопользовательская работа не поддерживается: одновременно с файлом должен работать один пользователь.

## Частые проблемы
- «Список пуст» при наличии записей — проверить `data/inventory.json` на корректность JSON.
- «Не найдено» при поиске — проверить ввод, убрать лишние пробелы.
- Ошибка при добавлении — заполнить обязательные поля, использовать допустимые состояния.
- Программа не запускается — проверить `python --version` и установить зависимости из `requirements.txt`.
